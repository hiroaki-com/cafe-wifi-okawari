カフェの無料 Wi‑Fi で「60分経ったので認証画面に戻された」ときに、自動で規約に同意し直して接続を戻す macOS 用の常駐スクリプトです。名前の okawari は、コーヒーの「おかわり」のように、時間切れのたびに Wi‑Fi をおかわりすることに由来します。

- 自分で規約に同意した Wi2 の Wi‑Fi では30秒ごとに接続状態を確認し、認証画面に戻されていれば再認証します（切れたことに30秒以内に気づき、通常はその数秒後に戻ります）
- 60分・30分など、制限時間の長さに関係なく動きます
- ID・パスワード・メールアドレスは使いません。保存もしません
- 追加のインストールは不要です（macOS 標準の zsh・curl・launchd だけで動きます）

## 対応している Wi‑Fi

ワイヤ・アンド・ワイヤレス（Wi2）の「規約に同意するだけ」の無料 Wi‑Fi に対応しています。

| お店 | SSID | 状況 |
|---|---|---|
| ドトール・エクセルシオール | `DOUTOR_FREE_Wi-Fi` | 確認中（同意の記録は動作確認済み。自動の再同意は未確認） |
| スターバックス | `at_STARBUCKS_Wi2` | 同じ仕組みのため動く見込み |
| タリーズ | `tullys_Wi-Fi` | 同上 |
| ガストなど すかいらーくグループ | `.Wi2_Free_at_【SK.GROUP】` | 同上 |
| ルノアール・ミヤマ珈琲 | `Renoir_Miyama_Wi-Fi` | 同上（1日3時間の上限は延長できません） |

会員登録やメール登録、アンケートが必要な Wi‑Fi（マクドナルド、サイゼリヤなど）には対応しません。調査結果は [DESIGN.md](DESIGN.md) にあります。

## 動作環境

macOS 15 以降（標準の `/usr/bin/jq` を使います）。Apple Silicon と Intel のどちらでも動きます。動作確認は macOS 27 で行いました。

## 利用前に確認してください

本ツールは、利用者本人に認められた無料 Wi‑Fi の再接続操作を自動化するための非公式ツールです。Wi2 および各店舗による公認・推奨を示すものではなく、作者も自動の再同意について Wi2 の許諾を得ていません。上の対応一覧は技術的な動作確認・見込みを示しており、自動操作についての許諾を示すものではありません。

### 利用できる範囲

- 利用する Wi‑Fi の最新の規約（Wi2 は [フリーWi-Fiサービス利用規約](https://wi2.co.jp/rules/free-wifi.html)）、接続条件、店舗の利用ルールを確認し、本人が利用を認められている範囲で使用してください。
- 再接続の回数制限がないことと、自動操作が許されていることは別です。自動操作や画面を経由しない接続方法の扱いが不明な場合は、提供者に確認できるまで通常の接続方法を使用してください。
- 利用時間・回数の上限、利用停止、本人確認、会員登録、アンケートなどの必要な手続きを回避する目的では使用しないでください。本ツールは利用時間や回数を数えません。店頭の案内も確認してください（たとえばドトールの[案内](https://www.doutor.co.jp/dcs/service/images/doutor_free_wi-fi.pdf)は、日本語では「60分経過後は再認証で接続可能」、英語では「60min three times per day」と書かれています）。
- 店舗や提供者から中止を求められた場合は、使用を中止してください。Wi‑Fi の再接続が可能でも、店舗の滞在時間などのルールは別に適用されます。

### 同意の自動送信について

初回は、利用者自身が接続画面で規約を確認して同意してください。本ツールは、接続の状態から同意済みと推定した接続先を記録します。macOS は認証画面つきの Wi‑Fi を同意するまで使わせず、本ツールは記録していない接続先では同意を送らないので、Wi2 の Wi‑Fi で通信できていれば、利用者が同意したと推定できます（本ツールが先に認証画面を見て、その後に通信が戻った場合も同じです）。以後は規約画面を表示せず、認証 API へ同意を示す情報（接続画面の「同意する」と同じ内容）を再送します。接続画面に出るお知らせも表示されません。この動作を理解し、自動の再同意を希望する場合に使用してください。

本ツールは、本人の同意操作そのものや規約の変更を検証しません。規約画面を表示しないので、画面に変更のお知らせが出ても気づけません。接続先の識別にも限界があり、店舗ごとの初回同意を保証するものではありません（同じブランドの別の店では、初回の同意なしに自動で送ることがあります）。規約の変更や新しい条件の提示を知った場合は、本ツールを停止し、内容を確認するまで自動再接続を再開しないでください。

### 利用を停止する場合

本ツールは、利用上限や利用停止による拒否と、一時的な通信障害を自動で区別できません。認証サーバーが同じ接続先で3回続けて同意を受け付けず、接続も戻らなかったときは、その接続先での自動の再同意を止めてダイアログで知らせます（接続画面で自分で同意し直すと再開します）。タイムアウトやサーバーエラーでは止めず、間隔を延ばして（最大30分）再試行を続けます。上限到達・利用停止が表示された場合や、失敗が続く場合は、自動再接続を停止して通常の接続画面を確認してください。

リポジトリのディレクトリで `./install.sh uninstall` を実行すると、常駐処理を停止・削除し、記録した接続先も削除します。

本ツールのライセンスは、Wi‑Fi サービスを利用する権利や、提供者の規約に反する操作の許可を与えるものではありません。

## 導入

```sh
git clone https://github.com/hiroaki-com/cafe-wifi-okawari.git
cd cafe-wifi-okawari
./install.sh
```

管理者権限（`sudo`）は使いません。スクリプトを `~/.local/bin/cafe-wifi-okawari` にコピーし、ログインユーザーの LaunchAgent として登録します。更新するときも `./install.sh` を再実行してください。

## 使い方

**最初の1回は自分で同意してください。** 記録していない接続先では、このツールは同意を送りません。Wi‑Fi につなぐと macOS が接続画面を開くので、利用規約を読み、自分で「同意する」を押してください。通信できるようになると、ツールは接続先を記録します（ログに `consent recorded … (online)`）。次に時間切れになったときからは、自動で再認証します。

- 時間切れのときに初めて認証画面を見た場合（接続したときに Wi2 だと分からなかった網など）は、何も送らず、「最初の1回だけ自分で同意してください」とダイアログで1回知らせます。接続画面は、Wi‑Fi に接続し直すか、ブラウザで `http://captive.apple.com` を開くと出ます
- 接続先は、店内の Wi‑Fi ルーターの MAC アドレスとブランド（`doutor` など）の組で見分けます。未登録の接続先では手動の同意を待ちます。ただし店舗を一意に識別できる保証はありません（同じブランドの店どうしで同じ値になることがあります）
- Wi2 の網かどうかは、網から配られるドメイン名（`wi2.ne.jp`）で見分けます（通信はしません）。自宅などそれ以外の Wi‑Fi では、つないでから5分間だけ macOS と同じく Apple の `captive.apple.com` で認証画面の有無を確かめ、Wi2 には何も送りません

お知らせは、2分で自動的に閉じるダイアログで表示します（macOS は常駐処理からの通知を画面に出さないため）。お知らせと `install.sh` のメッセージは、macOS の言語設定に合わせて日本語か英語で表示します。

## 削除

```sh
./install.sh uninstall
```

同意したお店の記録も消えます。ログ（`~/Library/Logs/cafe-wifi-okawari.log`）だけは残ります。不要なら手で削除してください。

## 困ったとき

動いているか（`state = running` か、`last exit code` が出ていれば登録されています）:

```sh
launchctl print gui/$UID/local.cafe-wifi-okawari | grep -E 'state|last exit code'
```

ログは、何かが起きたときだけ書きます:

```sh
tail ~/Library/Logs/cafe-wifi-okawari.log
```

| ログ | 意味 |
|---|---|
| `consent recorded net=… (online)` | 本ツールが何も送っていないのに Wi2 の網で通信できていたので、接続画面で自分で同意したお店として覚えた。次からは自動で再認証する |
| `consent recorded net=…` | 本ツールが認証画面を見たあとに自分で同意した。上と同じく覚えた |
| `consent pending net=…` | 記録していない接続先で認証画面を見た。自分で同意するのを待っている |
| `re-authenticated api=ok probe=ok net=… t=Ns` | 自動で再認証できた（同意を送り始めてから N 秒で通信が戻った） |
| `network changed net=…` | 再認証の途中で別の回線（テザリングなど）に切り替わった。その回の結果は成功とも失敗とも数えない |
| `login failed xN api=ng probe=ok` | このツールの認証は失敗したが、別の経路（macOS の認証画面など）で接続は戻った |
| `login failed xN api=… probe=ng` | 再認証できず、接続も戻っていない。ダイアログが出る。ルノアールなどで1日の利用時間の上限に達した場合もこうなる（延長はできない） |
| `auto stopped net=… rejected x3` | 認証サーバーが3回続けて同意を受け付けなかったので、この接続先での自動の再同意をやめた（利用上限・利用停止・条件の変更などの可能性）。ダイアログが出る。接続画面を確認し、自分で同意し直すと再開する |
| `redirect failed xN curl=… http=…` | 認証サーバーに届かない（タイムアウト・障害）。ダイアログは出ない |
| `redirect failed xN http=… to=…` / `no session_id` | 認証サーバーの応答が想定と違う（仕様変更の可能性）。記録済みの接続先ならダイアログが出る |
| `portal unknown xN` | Wi2 の網または記録済みの接続先で、Wi2 ではない認証画面が出た。何も送らない |
| `portal mismatch xN mac=… ip=…` | 認証画面がこの Mac ではない端末（MAC や IP アドレスが違う）向けだったので、何も送らない |
| `not free wi-fi xN` | 「規約に同意するだけ」の無料 Wi‑Fi ではない Wi2 の網。何もしない |
| `probe failed xN net=… curl=… http=…` | Wi2 の網・記録済み・同意待ちの接続先で、接続の状態を確かめられなかった（`curl` が 0 以外なら通信失敗、`http` は想定外の応答）。何も送らない |

失敗が続いたときは、試す間隔を 30秒 → 60秒 → … → 最大30分 と広げ、ログは 1・2・4・8… 回目だけ書きます。ダイアログは失敗が続く間に1回だけです（拒否が続いて自動をやめるときは、もう1回出します）。別のお店の Wi‑Fi に移ったときは、前のお店での待ち時間を引き継がずにすぐ試します。

## 注意

- **VPN・iCloud プライベートリレー**: 使っていると、認証画面に戻されたことを正しく判定できないことがあります
- **通信の暗号化**: 無料 Wi‑Fi の通信は暗号化されていません。このツールはつなぎ直すだけで、通信内容は守りません。大事な通信は HTTPS や VPN で守ってください
- **利用規約**: 最初の同意のあとは、規約画面を表示せず、認証 API へ同意情報を再送します。サーバー側の利用時間・回数の制限を解除する機能はありません。MAC アドレスの偽装や多重接続もしません。「[利用前に確認してください](#利用前に確認してください)」を読んだうえで使ってください
- 非公式のツールで、上記の各社とは関係ありません。各社の仕様が変わると動かなくなることがあります。規約・法令との関係の検討は [DESIGN.md](DESIGN.md) の §4 にあります
